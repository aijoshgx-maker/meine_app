# Bild-Kandidaten - Durchsicht

Erzeugt von `tool/bild_kandidaten.py`.

Aufgelistet sind Fragen, deren **Kategorie** zu einem der 9
vorhandenen Diagramme passt. Das heisst noch nicht, dass das
Diagramm der Frage auch wirklich hilft - genau das ist die
Entscheidung, die hier zu treffen ist.

**Faustregel:** Das Diagramm soll die Antwort stuetzen, nicht
die Seite fuellen. Wo es nur schmueckt, lieber weglassen.

Zuweisen anschliessend mit:

```bash
python tool/bild_zuweisen.py schnittdaten ft-zg-004 ft-sd-002
```
